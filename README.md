Exercício de jogo em Python: movimente o jogador, desvie dos inimigos e preserve suas três vidas.

## Controles

| Tecla | Ação |
|---|---|
| Setas | Movimentar o jogador |
| Escape ou X | Encerrar o jogo |

## Conceitos praticados

Classes de sprites, grupos, eventos, atualização por quadro e detecção de colisões.

## Como executar e limitações

Instale `pygame-ce` com `python -m pip install pygame-ce` e execute `python Tpygame.py`. O arquivo `eu ft.jpeg` não foi enviado e é obrigatório no código atual: sem ele o jogo interrompe a execução. Escape ou X encerram o jogo.

Código preservado conforme o arquivo enviado.
